# VerityMod
This extension will add a **Verity** gamemode! In this gamemode, Verity will randomly spy on you to gain extra information on your whereabouts. It's an extra Crewmate! You can then ask Verity in meetings things like "where was blue when reactor went off?"

## Settings

| Setting | Options | Explanation |
| -------- | -------- | -------- |
| Verity  | True/False  | Determines if Verity is turned on.  |
| How Crazy Is Verity  | 1-5  | At number 1, Verity is treated as a slow Crewmate and can barely see things. At number 5, Verity is a supernatural ghost that can move across the map super quickly.  |
| Honesty Level  | 1-5  | Verity will become less honest at 1 and brutally honest at 5. Setting this and the above setting at 5 is crazily OP for the Crewmates!  |
| Who Can See Verity  | Crewmates / Non-Crewmates / Everyone / No One  | Determines who can see Verity lurking in the ship! |
| Public Responses  | Always / If Specified / Never  | Determines if Verity's responses in meetings are always readable by everyone, only if the sender allows it, or never. |
